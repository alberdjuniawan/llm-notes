# Experiment 003: Supervised Fine-Tuning

This report contains the results and analysis of the experiment described in [`experiments/003-sft-135m/README.md`](../experiments/003-sft-135m/README.md).

## Dataset Processing

The raw SFT dataset contained 5 instruction-response examples. Each example was formatted as `User: {instruction}\nAssistant: {response}` and tokenized into a single variable-length sequence. Prompt tokens were assigned the label value `-100` so they were ignored by the training loss, while response tokens remained as prediction targets.

The prepared dataset contained 219 total sequence tokens, consisting of 71 prompt tokens and 148 response tokens. Sequence lengths ranged from 37 to 48 tokens, with an average of 43.8 tokens per example.

```text
5 examples -> 219 total sequence tokens -> 71 prompt + 148 response tokens
```

Unlike the CPT experiment, the SFT dataset was not divided into fixed-length blocks. Each instruction-response example remained a separate sequence, so padding was required when sequences of different lengths were combined into a batch.

## Training

The model was trained using full-parameter SFT for 10 epochs with a batch size of 1, learning rate of `5e-5`, AdamW optimizer, weight decay of `0.01`, FP32 precision, and seed `42`. Because the dataset contained 5 examples and the batch size was 1, each epoch consisted of 5 optimizer steps, resulting in 50 optimizer steps across the entire experiment.

The initial training loss was `1.4784`, while the final evaluation loss on the training dataset was `0.0021`.

Training loss decreased consistently across the experiment:

```text
Epoch 1:  1.2988
Epoch 2:  0.4543
Epoch 3:  0.1139
Epoch 4:  0.0389
Epoch 5:  0.0151
Epoch 6:  0.0086
Epoch 7:  0.0060
Epoch 8:  0.0042
Epoch 9:  0.0031
Epoch 10: 0.0024
```

The sharp decrease in loss indicates that the model successfully optimized the supervised response prediction objective on the provided training examples.

## Checkpoint Validation

The resulting SFT checkpoint was successfully reloaded from `outputs/003-sft-135m` and performed a forward pass successfully. The reloaded model contained 134,515,008 parameters and produced logits with shape `[1, 3, 49152]` for an input containing 3 tokens.

## Base vs SFT Generation

The base and SFT models were compared using the same instruction-format prompts with deterministic decoding so that differences were primarily attributable to the different model weights rather than sampling randomness.

For the five prompts represented in the training dataset, the base model frequently continued text patterns or question templates instead of directly answering the instruction. The SFT model instead produced responses corresponding to the supervised examples.

For example, given `User: Explain photosynthesis for a fifth-grade student.\nAssistant:`, the base model continued with another question-style pattern, while the SFT model directly produced the corresponding educational explanation.

The other training-set prompts showed the same general pattern, with the SFT model producing direct responses for the solar system, fractions, the role of the Sun, and the importance of sunlight.

The generation comparison therefore demonstrates a clear behavioral difference between the original base model and the SFT checkpoint on the training examples.

## Unseen Prompt Generation

The SFT model was also tested on five prompts that were not present in the training dataset. These prompts covered evaporation, lunar phases, mass and weight, the role of roots in water absorption, and multiplication.

The SFT model continued to produce direct responses following the instruction-response format for these unseen prompts, while the base model more often continued document-like or question-template patterns.

For example, the SFT model responded directly to `User: How do roots help a plant get water?\nAssistant:` with a concise answer rather than continuing a repeated question pattern.

This result provides qualitative evidence that the instruction-response behavior was not limited to exact reproduction of the five training prompts. However, the test used only five unseen prompts and did not provide a quantitative measure of generalization.

## Weight Delta Analysis

A parameter-by-parameter comparison was performed between the original base model and the SFT checkpoint.

```text
Total parameters:       134,515,008
Changed parameters:     134,509,022
Unchanged parameters:         5,986
Changed percentage:          99.9955%
Mean |delta|:                0.00027921
Max |delta|:                 0.00193069
```

The results show that nearly all parameter values changed during training, confirming that this experiment performed full-parameter SFT rather than training a separate adapter.

The largest mean absolute changes were observed in individual parameter tensors such as `model.layers.28.self_attn.v_proj.weight`, `model.layers.27.self_attn.k_proj.weight`, `model.layers.27.input_layernorm.weight`, `model.layers.27.self_attn.q_proj.weight`, and `model.layers.28.self_attn.k_proj.weight`.

These entries represent individual parameter tensors rather than complete Transformer layers, and each Transformer layer contains multiple parameter tensors.

## Interpretation

The experiment provides three main pieces of evidence that the SFT training process worked: training loss decreased substantially, the SFT model produced direct responses to instruction-style prompts, including unseen prompts, and nearly all model parameters changed during full-parameter training.

The observed behavior is consistent with the SFT mechanism in which the model receives an instruction-response sequence, uses the instruction as context, and computes the supervised next-token prediction loss primarily on the response tokens. The prompt labels were set to `-100`, causing those positions to be ignored by the cross-entropy loss.

Unlike CPT, which applies the next-token prediction objective across raw corpus text, SFT explicitly structures the training data as instructions and desired responses. The underlying causal language modeling mechanism remains the same, but the supervised targets are different.

## Generalization Observation

The training-set comparison showed that the SFT model closely reproduced the responses represented in the training data. The unseen-prompt comparison showed that the model could also produce direct responses for instructions that were not present in the training dataset.

This suggests that SFT can learn a response pattern rather than only memorizing exact input strings. However, the unseen prompts were limited in number and remained within a similar educational domain and instruction format, so this result should not be treated as evidence of broad generalization.

## Overfitting

The dataset contained only 5 examples, and the model was trained for 10 epochs, giving the model repeated exposure to a very small amount of supervised data. The resulting final loss of `0.0021` therefore indicates that the model fit the training examples very closely rather than demonstrating broad instruction-following ability.

The close match between SFT generations and the training responses further supports this interpretation.

A meaningful evaluation of SFT generalization would require a larger and more diverse dataset together with a held-out evaluation set containing instructions that are not used during training.

## Limitations

This experiment was designed to validate the mechanics of local SFT rather than measure general instruction-following performance. The experiment used only 5 examples, 50 optimizer steps, and no separate validation dataset. The unseen-prompt evaluation was qualitative and used only 5 manually selected prompts.

The experiment also demonstrates that improved instruction-following behavior does not necessarily imply factual correctness. At least one unseen response contained an incorrect explanation of evaporation, showing that response format and factual accuracy are separate properties.

## Conclusion

The experiment successfully demonstrated the complete local SFT pipeline from instruction-response preprocessing and label masking through supervised training, checkpoint creation, checkpoint reload, generation comparison, unseen-prompt evaluation, and parameter-delta analysis. The results show that SFT can shift a pretrained causal language model toward directly responding to instruction-style inputs, while the very small training dataset limits any conclusions about broad generalization or factual performance.
