# Experiment 002: Continued Pre-Training

This report contains the results and analysis of the experiment described in [`experiments/002-cpt-135m/README.md`](../experiments/002-cpt-135m/README.md).

## Dataset Processing

The raw corpus contained 135 tokens after tokenization. Using a block size of 64 produced 128 usable tokens and 2 complete training sequences, while the remaining 7 tokens were discarded because they did not form a complete sequence.

```text
135 tokens -> 128 usable tokens -> 64 + 64
```

The preprocessing pipeline converted the raw text into token IDs using the SmolLM2-135M tokenizer and then grouped the token stream into fixed-length sequences suitable for causal language model training.

## Training

The model was trained using full-parameter CPT for 10 epochs with a batch size of 1, learning rate of `5e-5`, AdamW optimizer, weight decay of `0.01`, FP32 precision, and seed `42`. Because the dataset contained only 2 sequences and the batch size was 1, each epoch consisted of 2 optimizer steps, resulting in 20 optimizer steps across the entire experiment.

The initial training loss was `1.6450`, while the final evaluation loss on the training corpus was `0.0044`.

Training loss decreased consistently across the experiment:

```text
Epoch 1:  1.6238
Epoch 2:  0.7820
Epoch 3:  0.4150
Epoch 4:  0.2586
Epoch 5:  0.1134
Epoch 6:  0.0515
Epoch 7:  0.0279
Epoch 8:  0.0134
Epoch 9:  0.0086
Epoch 10: 0.0059
```

The sharp decrease in loss indicates that the model successfully optimized the next-token prediction objective on the provided training corpus.

## Checkpoint Validation

The resulting CPT checkpoint was successfully reloaded from `outputs/002-cpt-135m` and performed a forward pass successfully. The reloaded model contained 134,515,008 parameters and produced logits with shape `[1, 3, 49152]` for an input containing 3 tokens.

## Base vs CPT Generation

The base and CPT models were compared using the same prompts with deterministic decoding so that differences were primarily attributable to the different model weights rather than sampling randomness.

For the prompt `Photosynthesis is`, the base model produced a general explanation of photosynthesis, while the CPT model closely followed the wording of the training corpus.

For the prompt `The solar system consists of`, the CPT model closely reproduced the corresponding training text, while the base model generated a different general continuation.

For the prompt `A fraction represents`, the CPT model again closely followed the wording found in the training corpus, while the base model generated a different general explanation.

The generation comparison therefore shows a clear behavioral difference between the original base model and the CPT checkpoint.

## Weight Delta Analysis

A parameter-by-parameter comparison was performed between the original base model and the CPT checkpoint.

```text
Total parameters:       134,515,008
Changed parameters:     134,512,851
Unchanged parameters:         2,157
Changed percentage:          99.9984%
Mean |delta|:                0.00031303
Max |delta|:                 0.00101588
```

The results show that nearly all parameter values changed during training, confirming that this experiment performed full-parameter CPT rather than training a separate adapter.

The largest mean absolute changes were observed in individual parameter tensors such as `model.layers.28.post_attention_layernorm.weight`, `model.layers.25.input_layernorm.weight`, `model.layers.29.self_attn.q_proj.weight`, `model.layers.29.post_attention_layernorm.weight`, and `model.layers.29.mlp.up_proj.weight`.

These entries represent individual parameter tensors rather than complete Transformer layers, and each Transformer layer contains multiple parameter tensors.

## Interpretation

The experiment provides three main pieces of evidence that the CPT training process worked: training loss decreased substantially, the CPT model generated text that differed from the base model and closely followed the training corpus, and nearly all model parameters changed during full-parameter training.

The observed behavior is consistent with the CPT mechanism in which the model repeatedly predicts the next token in the training corpus, computes the prediction loss, performs backpropagation, and updates its existing weights through the optimizer.

The very low final training loss and the close similarity between CPT generations and the training corpus indicate that the model fit the tiny corpus very closely.

## Data Pipeline Observation

The corpus was tokenized and concatenated into a single token stream before being divided into fixed-length sequences, which means the model could learn token patterns that cross paragraph boundaries.

For example, the CPT model continued from the photosynthesis content toward the solar-system content, demonstrating that corpus structure can influence the patterns learned during CPT.

A larger real-world corpus should therefore handle document boundaries explicitly and should include stronger preprocessing, deduplication, quality filtering, provenance tracking, and dataset versioning.

## Overfitting

The corpus contained only 135 tokens and 2 training sequences, so the model received repeated exposure to an extremely small amount of data. The resulting training loss of `0.0044` should therefore be interpreted as evidence that the model fit the training corpus very closely rather than evidence that the model acquired general educational knowledge.

A meaningful evaluation of domain adaptation would require a substantially larger corpus and a held-out validation set that is not used to update the model weights.

## Limitations

This experiment was designed to validate the mechanics of local CPT rather than measure generalization or educational-domain performance. The experiment used only 135 tokens, 2 training sequences, 20 optimizer steps, and no held-out validation data. Because the same corpus was used for optimization and final loss evaluation, the final loss cannot be used as a measure of generalization.

## Conclusion

The experiment successfully demonstrated the complete local CPT pipeline from raw text preprocessing and tokenization through next-token training, weight updates, checkpoint creation, checkpoint reload, generation comparison, and parameter-delta analysis. The results also demonstrate why dataset scale, document structure, and evaluation methodology become important when moving from a small learning experiment to a real educational CPT pipeline.
